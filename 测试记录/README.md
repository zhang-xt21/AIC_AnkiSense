# 历史测试记录

本目录保存原开发阶段的 Markdown 验收说明，作为版本与已知问题的线索。**这些是当时环境的记录，不是新仓库或新机器已执行的测试。** 文中“当前服务”“已安装”“本目录生成”等表述均指报告日期的原测试环境。

源码仓库没有复制历史个人数据库、真实讲义、截图、模型缓存、安装包、原始 JSON 或日志。未随仓库分发的产物以文字名称保留，不能在新克隆目录直接打开。原始产物仍由执行者在原测试空间单独保存；需要复验时使用自己的获准材料，在隔离目录重新生成。
