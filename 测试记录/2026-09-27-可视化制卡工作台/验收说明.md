日期：2026-09-27。测试使用独立数据库、自制 PDF / 图片和虚拟模型配置；未修改个人资料，未调用真实云端模型。OCR 和 Docling 的真实模型解析质量不是本轮验收范围。

## 已实现

- 真实制卡页改为讲义、编辑、正反面预览三栏；小屏切换三个区域。
- 课程 / 状态筛选、前后切卡、会话内草稿保留。
- PDF 原页放大与切页，可读引用及逐条评分要点编辑。
- 复用推荐、裁剪、上传、原页配图；预览读取草稿，练习与导出读取已保存版本。
- 新增模型设置页面及 GET / PUT `/api/settings/ai`，本机持久化、即时生效、密钥不回显，忙任务期间禁止切换设置。
- 卡片可选 `expected_version` 校验，旧草稿保存返回 409 并保留内容；用户明确确认后可载入最新版本。

## 本轮发现并修复

1. 生成期间切换课程，工作台可能用新课程筛选隐藏刚返回的卡片：改为定位生成请求所属课程。
2. 无效超时参数在折叠的高级设置中无法看到：原生校验失败时自动展开。
3. 图片位置调整后整个页面重绘会跳回中栏顶部：保存同一卡片各栏的滚动位置。
4. 文字输入反复重建图片预览：图片和显示面未变化时只更新文字，保留媒体节点。

## 复现

需要项目 Python 虚拟环境、Node、Playwright 和 Chrome。浏览器工具会自动准备测试素材与数据目录，结束后停止自己的服务。

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_app.py tests/test_model_settings.py tests/test_llm.py tests/test_attempt_service.py tests/test_card_images.py tests/test_figure_recommendations.py tests/test_figure_vision.py tests/test_plugin_api.py tests/test_apkg.py
node --test tests/card-images.test.cjs tests/figure-recommendations.test.cjs tests/practice-progress.test.cjs tests/export.test.cjs
node tools/workbench_check.cjs
node tools/model_settings_check.cjs
```

浏览器产物分别位于 `.ui-checks/20260927-workbench/run-*` 和 `.ui-checks/20260927-model-settings/run-*`。测试工具源代码保存在 `tools`，不依赖已有临时产物。

原测试空间曾保留最终 工作台报告（历史外部产物 `workbench-report.json`，未随源码分发）、设置报告（历史外部产物 `settings-report.json`，未随源码分发）、图文工作台截图（历史外部产物 `workbench.png`，未随源码分发） 和 模型设置截图（历史外部产物 `model-settings.png`，未随源码分发）。

## 验证边界

本轮没有使用用户密钥验证真实服务商连接或评估出题、评分、视觉识别准确率；保存配置不代表能力验证。配图与人工核对沿用现有规则，不新增自动批准。图片挖空和 Anki 内嵌制卡窗口仍为后续范围。
