> 归档记录：以下环境、服务状态和结果属于报告日期；历史截图、数据库、JSON 与日志未随源码分发，见[测试记录索引](../README.md)。

测试日期：2026-09-25。独立测试服务：`http://127.0.0.1:8767`，未改动主学习空间的数据。浏览器操作使用 CUA 的真实网页交互。

## 结论

扫描 PDF 的“查看原图 → 编辑 → 切页保留草稿 → 确认保存 → 当前片段可制卡”流程通过。并发修改会阻止旧版本覆盖，原始 OCR 文字仍可查看。桌面与 390px 窄屏均未发现页面横向溢出。

| 检查 | 实际结果 |
| --- | --- |
| 扫描页原图 | 页面图片成功加载，图像宽 2308px；可与识别文字对照 |
| 扫描页人工校对 | `scanned-lecture-8-10` 第 2 页已按真实原图核对，保存为 revision 2 / reviewed |

| 切页草稿 | 编辑第 2 页，切至第 3 页再返回；编辑全文仍保留 |
| 未保存时重识别 | 有草稿时“重新 OCR 此页”禁用，防止覆盖输入 |

`node --check ankisense/static/app.js` 通过。测试结束后已重置临时视口尺寸。

## 本次 UI 验证中修正的问题

- 校订后的片段原先可能落到列表末尾，现按物理页码与片段编号排序。
- 原图的新标签打开在内置浏览器中没有可见响应，改为页内原图预览，保留校对草稿与焦点。
- 初次未识别出文字的页面不能显示为“已确认空白”，改为依据人工确认时间区分。
- 原文更新导致所有卡片退回草稿时，练习页仍保留最近历史记录入口；卡片审核区同时展示历史引用与当前原文。
