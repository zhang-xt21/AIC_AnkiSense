# APKG 官方 Anki 兼容验收

> 归档记录：以下环境、服务状态和结果属于报告日期；历史截图、数据库、JSON 与日志未随源码分发，见[测试记录索引](../README.md)。

2026-09-25，本机官方 Anki 26.09.3 后端验收通过 **24 项检查**。详细断言与导入日志见 `official-anki-result.json`。

## 验收范围

- 使用项目实际 `/api/export/apkg` 接口输出文件，再交给本机官方 Anki 的 `Collection.import_anki_package()` 导入。
- 初次导入只产生 2 张已批准卡片，草稿及拒绝卡片不进入包中。
- 题面图片在正面显示；答案图片只在答案面显示。图片说明转义正常；图片文件字节一致。
- 卡片包含指向本机 AnkiSense 的练习链接。
- 通过 Anki 自身调度器实际作答一次，生成复习记录。
- 再次导入同一包，不重复创建卡片，保持笔记 ID、GUID、调度信息及复习记录。
- 导入较新版本，按默认“较新时更新”策略更新答案，并保持上述标识、调度与记录。
- 默认策略不会用旧包覆盖新内容；明确设为“始终更新”后旧包可以覆盖字段，但卡片数量、标识、调度和复习记录仍保持。

## 隔离措施与限制

生成材料使用临时演示数据库和两张合成色块图片，全程没有调用云端 AI。官方 Anki collection 也创建在本目录临时子目录内，并在测试后关闭清理。未打开、修改用户的 `origin/AnkiData` 或项目正式 `data`。

这是**官方程序后端兼容性验收**，没有自动操作桌面 Anki 导入对话框，也不代表已完成手机端、旧版 Anki 或真实讲义内容准确率测试。

Anki 的默认导入策略按秒比较内容更新时间。本次两个导出版本间隔 1.2 秒。同秒快速重导、或用户已在 Anki 修改了字段时，可在导入选项选择“始终更新”；这意味着以导入包字段覆盖现有字段。生产代码没有人为生成未来时间戳。

`preview-question.html`、`preview-answer.html` 是 Anki 实际模板渲染结果的独立浏览器预览（图片已内嵌），并非桌面截图。`fixtures/*.apkg` 仅供验收，含演示数据。

## 复现

在项目根目录运行：

```powershell
& '.\.venv\Scripts\python.exe' '.\测试记录\2026-09-25-apkg\make_acceptance_packages.py'
& '.\测试记录\2026-09-25-apkg\run_anki_backend.ps1' -Script '.\测试记录\2026-09-25-apkg\verify_with_official_anki.py'
```

第二条利用官方 Anki 内嵌 Python 3.13 运行官方模块，不安装额外 Anki 包、不启动桌面窗口。项目 Python 3.12 不能直接读取这些 3.13 的 `.pyc`，所以提供专用隔离宿主。
