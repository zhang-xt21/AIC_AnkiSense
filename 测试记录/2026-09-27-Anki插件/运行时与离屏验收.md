# Anki 运行时与离屏界面验收

> 归档记录：以下环境、服务状态和结果属于报告日期；历史截图、数据库、JSON 与日志未随源码分发，见[测试记录索引](../README.md)。

官方安装：`origin/Anki`。实测 Anki **26.09.3**、内置 Python **3.13.15**。

## 可重复运行

以下命令从项目根目录执行，输出保存在项目下的独立测试目录。

```powershell
& ./tools/run_anki_python.ps1 -Script tools/inspect_anki_runtime.py -DataDirectory "测试记录/2026-09-27-Anki插件/runtime-inspection"
& ./tools/run_anki_python.ps1 -Script tools/test_anki_plugin_ui.py -DataDirectory "测试记录/2026-09-27-Anki插件/ui-smoke-final"
```

运行器始终创建独立 PowerShell 子进程，再以 P/Invoke 加载官方安装中的 `python313.dll`。不安装依赖，不修改 Anki 安装。测试代码通过 `ANKISENSE_ANKI_TEST_ROOT` 获取独立数据目录；Collection 构造被限制在这个目录内，个人 Anki 资料文件不允许访问。

默认 Python 网络调用被拒绝。只有明确使用 `-AllowLoopback` 时，允许数值地址 `127.0.0.1`、`::1`；仍拒绝域名和外网。运行器是测试防误操作工具，并非操作系统级安全沙箱；验收脚本不调用 Anki 内建在线同步，也不调用云端 AI。

## 真实 API 差异

- `QueryOp` 的 `success` 在构造函数中传入，没有 `.success()` 链式方法。
- `CollectionOp` 的操作返回 `OpChanges` 或带 `.changes` 的结果；普通字典不符合约定。
- `DeckManager.all_names_and_ids(include_filtered=False)` 可排除筛选牌组；没有 `skip_filtered` 参数。
- `profile_will_close` 和 `profile_did_open` 钩子都不传参数。
- `mw.reset()` 是旧接口；本插件使用 CollectionOp 触发集合界面刷新。
