# AnkiSense

**从讲义到有依据的图文卡片，再到主动回忆与复习。**

AnkiSense 是面向课程学习的独立桌面软件。用户导入讲义后，系统提取学习目标、生成图文卡片并检查引用与答案；学习时用自己的话回答，查看反馈并回到原文核对。需要间隔复习时，可通过自有插件同步到 Anki。

## 核心流程

```text
导入 PDF / PPT → 提取文字与原页 → 提取学习目标 → 生成图文卡片
                                                   ↓
                                            来源与内容检查
                                          ↙              ↘
                                    有疑点，修复或处理     通过，进入学习
                                                            ↓
                                          自由作答 → 反馈 → 回看依据
                                                            ↓
                                              可选：同步 Anki 复习
```

- **自动制卡**：支持系统建议或自定张数，保留任务进度、有效结果和未完成原因，可取消和继续。
- **图文与公式**：引用讲义原页、裁剪配图并选择显示侧；桌面卡片支持本地 LaTeX 渲染。
- **有依据的检查**：校验引用、来源版本、题目、参考答案和评分要点，保留审核疑点；多目标卡片可进入拆分补做流程。
- **主动回忆**：输入自己的解释，查看涉及、遗漏或矛盾的要点，并回到引用原文。
- **Anki 集成**：导出 APKG，或使用插件同步图文卡片、在 Anki 内作答；复习排期由 Anki 负责。

机器检查不能保证内容完全正确。有疑点的候选不应被当作已验证的学习内容；当前作答分析以文字为依据，不直接理解卡片图片。

## 我们实现了什么

本项目是独立仓库，**不是 Anki 官方源码的分叉**。

| 层次 | 实现与作用 |
| --- | --- |
| AnkiSense 自有实现 | 学习目标与卡片工作流、来源版本和引用校验、配图与审核交互、定向修复与失败隔离、作答反馈、Anki 配对与同步插件 |
| 文档与图像基础 | RapidOCR / ONNX Runtime 识别文字，pypdf / pypdfium2 读取和渲染 PDF，Pillow 处理图片 |
| 应用基础 | FastAPI 提供本机服务，SQLite 保存数据，Electron 提供桌面窗口，KaTeX 显示公式 |
| Anki 生态复用 | genanki 生成 APKG；用户单独安装 Anki，使用其学习记录与间隔复习能力 |
| 模型服务 | 用户自行配置 API，用于提取、生成、审核及作答诊断；无密钥演示使用有限本地规则 |

研究与验证重点是：生成内容能否对应来源、失败候选能否被隔离、反馈能否帮助核对理解。上游组件与许可见[第三方声明](THIRD_PARTY_NOTICES.md)。

## 快速试用

### Windows 安装版

安装包将通过 [GitHub Releases](https://github.com/zhang-xt21/AIC_AnkiSense/releases) 发布。**0.1.19 当前为本地构建，尚未在本轮发布**；页面没有对应附件时，请使用源码启动。

安装版包含 AnkiSense 后端、网页及 Anki 插件文件，不包含 Anki 主程序。独立制卡和学习不需要安装 Anki；模型 API 由使用者自行配置。PPT/PPTX 转换需要本机 PowerPoint 或 LibreOffice，PDF 无此要求。

### 源码启动

主要开发环境：Windows PowerShell、Python 3.12。从仓库根目录运行：

```powershell
.\setup.ps1
.\start.ps1
```

打开 <http://127.0.0.1:8765>。保持终端运行，停止时按 `Ctrl+C`；端口占用可用 `.\start.ps1 -Port 8766`。初始化不会覆盖已有配置。

默认演示模式无需 API 密钥。在「学习材料」导入自编演示材料，完成卡片核对后练习和导出。该模式验证交互流程，**不是实际 AI 质量演示**。完整步骤和示例回答见[演示指南](docs/user/演示指南.md)。

真实自动制卡需在「模型设置」填写兼容接口地址、模型名和密钥，并验证连接；涉及原图检查时需模型支持图片输入。文字验证成功不等于图片能力可用。导入和检查会按当前配置发送相关文字或原图并消耗模型额度，详见[AI 接入指南](docs/user/AI接入指南.md)。

### 连接 Anki

在「导出至 Anki」使用连接向导：选择程序与资料位置 → 正常退出 Anki 后安装并配对插件 → 重启 Anki 等待回执 → 在 Anki 工具菜单中同步。只导入 APKG 的卡片仍需完成插件同步关联，才能安全使用 Anki 内作答。

同步使用稳定 ID 与内容基线，保留复习进度；本地编辑冲突会提示核对。详细步骤见[插件说明](docs/user/Anki同步插件使用说明.md)。

## 验证与当前限制

0.1.19 已有本地单元、浏览器和打包程序隔离验证记录；验证范围、运行命令与未验证项目集中在[测试结论](docs/evaluation/测试结论.md)。这些是开发验收结果，不是整体学习效果或模型准确率。

仍需完成：干净 Windows 环境的安装与升级验收，以及冻结版本上的独立人工标注评估。复杂公式识别、图表理解和首次拆分粒度仍可能失败；渲染公式不等于识别正确。

## 目录与开发

| 目录 | 内容 |
| --- | --- |
| `ankisense/` | 后端与网页静态资源 |
| `desktop/` | 桌面窗口、后端打包、安装器 |
| `addons/` | Anki 插件源码 |
| `examples/` | 自编演示与格式示例 |
| `tests/`、`tools/` | 自动化测试、构建和验收工具 |
| `docs/` | 使用说明、开发说明、评估结论和历史记录 |

常用测试命令：

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
npm test
npm run test:browser
```

浏览器测试需 Node.js 20 或更新版本及测试环境，可运行 `.\setup.ps1 -IncludeBrowserTests` 准备。默认离线测试不调用真实模型；Anki 集成验收使用专用运行器和隔离资料。桌面构建见 [desktop/README.md](desktop/README.md)。

## 数据与许可

源码运行的数据默认位于 `data/`；安装版使用用户数据目录。模型配置、密钥、个人讲义、学习记录和 Anki 资料不随源码分发。密钥存于本机配置，分享前不要复制配置或数据目录。备份学习数据时先停止服务，再备份完整数据目录。
