# 协作仓库准备验收

日期：2026-09-27。对象：本目录的独立 AnkiSense 仓库，不是 Anki 源码分叉。

## 整理范围

从原型目录复制业务源码、Anki 插件源码、测试、依赖锁定文件、配置示例、自编演示材料和历史文字报告。原型目录仍保留，未迁移或覆盖其中的个人学习资料。

没有复制真实课程 PDF、用户上传图片、个人 SQLite 数据库、模型密钥、插件连接凭据、已安装 Anki、虚拟环境、模型缓存或原始测试运行产物。仓库里的 `bootstrap.apkg` 经检查仅有一个专用模板占位笔记。

补充了初始化脚本、协作规则、架构分工、路线图、第三方组件说明、PR/Issue 模板和 GitHub Actions 配置。默认 Git 分支为 `main`；没有配置远程仓库或推送到第三方服务。

## 本目录实际验证

| 检查 | 结果 |
| --- | --- |
| `setup.ps1` 默认流程 | 在本目录新建 `.venv`，安装 `requirements.lock.txt`，`pip check` 通过，创建默认演示 `.env` |
| `python -m pytest -q -rs`（本目录虚拟环境） | 520 通过，13 跳过，2 条依赖弃用警告；44.64 秒 |
| 初始化专项测试（包含在总数内） | 11 通过；同时在正常 PowerShell 执行策略下复核，无需覆盖执行策略 |
| `npm ci` / `npm test` | 依赖安装成功，46 项前端单元测试通过 |
| `npm run test:browser` | 反馈 6、制卡工作台 13、模型设置 13，共 32 项通过 |
| Git 忽略规则 | 默认配置、数据、凭据、安装包、虚拟环境和模型不会进入源码提交；配置示例及插件模板保留 |
| 仓库静态检查 | 插件默认连接路径为空；源码文件无大体积运行包；简单凭据模式检查无命中；CI YAML 解析通过 |

13 项跳过分别为：5 项需要当前系统不允许创建的测试符号链接，1 项需要额外的官方 Anki 运行时，7 项需要独立 Docling 环境。没有通过放宽测试结果解决缺少依赖的问题。

初始化专项测试在临时目录验证：重复运行保留 `.env`、现有连接 token、停用状态、学习文件和插件 `user_files`；错误哈希和中断下载不采纳安装包；校验缓存可复用；程序路径保存与脚本语法可用。

浏览器验收通过 `CHROME_PATH` 使用已有 Chrome，服务、npm 依赖和 Python 依赖来自本目录。没有读取个人浏览器资料、调用真实云端模型或操作个人 Anki 学习库。

## 尚未实测或尚未完成

- GitHub Actions 仅完成配置和本地对应命令验证；远程仓库尚未建立，不能宣称远程 CI 已通过。
- 没有在本轮重新下载或执行真实 Anki MSI。下载与校验使用固定官方版本及 SHA256，测试中的成功下载是模拟结果。
- `-IncludeAnki` 在缺少程序时负责下载、校验、准备独立插件资料，首次仍需用户完成官方安装确认。已经安装时可传 `-AnkiRoot`。
- 没有重新下载 Docling 模型或 Playwright 默认 Chromium，相关安装选项仍需在新电脑验证。
- 本轮验证工程可复现性，不评估 AI 语义准确率或学习效果。
- 团队尚需决定公开发行许可证；现有第三方来源见 [组件记录](../THIRD_PARTY_NOTICES.md)。
