# 可视化制卡工作台与模型设置

工作台使用当前 AnkiSense 数据目录中的讲义、卡片、配图和历史练习。新克隆的源码目录默认创建独立空学习空间，不会自动继承旧开发目录的数据；首次安装见 [README](../README.md#启动)。

## 启动更新后的版本

本次同时修改了前端和后端。请先保存正在编辑的卡片，等生成或分析结束，再在原来的服务终端按 `Ctrl+C`，从项目根目录（包含 `start.ps1` 的文件夹）重新运行：

```powershell
.\start.ps1
```

打开 <http://127.0.0.1:8765/>，按 `Ctrl+F5` 刷新。不要同时启动两个使用同一数据目录的服务。

## 做一张图文卡片

1. 在「学习材料」导入讲义，校对需要的页面，选取原文生成草稿。也可以导入演示材料，先体验本地流程。
2. 打开「制卡工作台」。顶部可按课程、审核状态筛选，使用下拉框或前后按钮切换卡片。
3. **左侧讲义与依据**：切换讲义页，点击原页图片放大；查看引用及上下文，点击「加入卡片引用」补充依据。历史引用会保留标记，方便和新原文核对。
4. **中间编辑卡片**：修改问题、参考答案、知识概念，逐条编辑评分要点与原文引用。引用须对应原文，不再需要手填 JSON。
5. 在中间「讲义配图」中，复用「推荐配图」和「预览与裁剪」，或上传截图、附加讲义原页。修改问题或引用后，应先保存，再重新推荐。推荐不足时可以不配图。
6. **右侧卡片预览**：切换「正面 / 背面」。输入文字、添加图片、调整图片位置或说明后立即看到效果。默认把新增图片放在背面；看图作答时才改到题目侧，避免提前显示答案。
7. 点击「保存草稿」，或核对后「核对并批准」。新采纳的推荐图片需要先保存为草稿，再明确批准。批准后的图文卡片可进入练习、APKG 导出和已有 Anki 插件同步。

小屏幕使用「查看讲义 / 编辑内容 / 卡片预览」三个按钮切换区域。制卡预览展示未保存的编辑；练习及导出读取已保存、已批准的版本。

切换卡片或导航页时，未保存内容在当前页面会话内保留；刷新或关闭页面前需要保存。若另一窗口更新了同一卡片，保存会提示版本冲突并保留当前草稿。先复制需要保留的修改，再使用「载入最新版本」重新编辑。

## 在页面中配置模型

进入侧栏「模型设置」：

- 选择「演示模式」或「自配 API」。
- 填写兼容 Chat Completions 的 **Base URL**、服务商给出的模型名称和 API Key。地址不要附加 `/chat/completions`。
- API Key 留空表示保留已有密钥；需要替换时填入新值。勾选「保存时清除已保存的密钥」才会删除旧密钥。更换服务器时需要重新填写或清除密钥。
- 「高级设置」可修改请求超时，范围 1–180 秒。
- 保存后用于后续生成、回答分析和已配置的图片检查，无需再次重启。正在生成或分析时，请等待任务结束再保存设置。

保存设置不会调用模型，也不代表连接或视觉能力已验证。模型是否支持图片输入，仍需按服务商能力选择。

配置保存到当前数据目录的 `model-settings.json`；默认是 `data/model-settings.json`。密钥保存在本机配置文件中，**未加密**，不会回显到网页，也不会写入卡片、浏览器存储或导出文件。不要分享该配置文件。尚未在页面保存配置时，项目继续读取现有环境变量 / `.env`；一旦保存，页面配置优先生效。

## 这次范围

已接入真实编辑、配图、预览、保存、审核与模型设置。图片挖空、Anki 内嵌制卡窗口仍是后续功能。回答分析目前仍以文字原文和评分要点为依据；配图的视觉检查是单独操作，不会因保存配置或切换预览而自动发送图片。

## 验证方式

浏览器检查工具使用独立测试目录和端口，禁止真实云端请求，不修改个人数据库：

- `tools/workbench_check.cjs`：编辑、配图、预览、版本冲突、练习显示与多宽度检查。
- `tools/model_settings_check.cjs`：设置保存、密钥处理、状态更新与错误恢复检查。
- Python 的 `tests/test_model_settings.py` 覆盖设置校验、持久化、即时生效、并发保护和卡片版本冲突。

本次离线测试可以验证程序流程；不等于已测试任意模型服务的连接、生成质量或视觉判断准确率。
