# 讲义制卡工作台与模型设置

工作台使用当前 AnkiSense 数据目录中的讲义、卡片、配图和历史练习。新克隆的源码目录默认创建独立空学习空间，不会自动继承旧开发目录的数据；首次安装见 [README](../README.md#启动)。

## 启动更新后的版本

本次同时修改了前端和后端。请先保存正在编辑的卡片，等生成或分析结束，再在原来的服务终端按 `Ctrl+C`，从项目根目录（包含 `start.ps1` 的文件夹）重新运行：

```powershell
.\start.ps1
```

打开 <http://127.0.0.1:8765/>，按 `Ctrl+F5` 刷新。不要同时启动两个使用同一数据目录的服务。

## 在一个入口完成讲义制卡

侧栏只有一个「讲义制卡」入口，顶部按顺序显示「导入讲义」「制作卡片」「检查结果」三步。

1. **导入讲义**：上传 PDF 或粘贴文字后，默认使用本次导入的全部有效原文。系统按文字量和可用范围在本机估算建议张数，可改为 1–30 张，或恢复建议值，再点击「开始制卡」。高级设置可指定原文片段。原文检查默认折叠，不要求先逐页确认；需要时对照原图修正识别结果。
2. **制作卡片**：顶部可按课程、卡片状态筛选，用下拉框或前后按钮切换卡片。左侧讲义可切换页码、放大原图、查看引用并补充依据；中间修改问题、答案、知识概念和评分要点。引用须对应原文，无需手填 JSON。
3. 生成时默认自动匹配讲义图片，可在制卡入口关闭。辅助图放答案侧，必须看图的题目放题目侧；只在图片检查通过后自动附上。界面显示匹配、检查或需要处理状态，必要时在「讲义配图」中推荐、裁剪或上传截图。修改问题或引用后，先保存再重新推荐。没有必需图片的题目暂不进入学习；其他卡片可以只用文字。右侧预览随编辑更新，可切换正面／背面。
4. 配置云端模型后，生成或保存草稿会自动排队检查配图和文字，通过即自动批准进入学习；有疑点显示原因，修改保存后重新检查。按钮旁说明 API 发送范围和费用，图片检查可能发送裁图与对应原页，无需逐张点击检查。

原文检查是可选操作；从左侧「检查第 N 页原文」可直接定位。保存原文但未改文字时保留已有卡片和引用；实际改文后需更新关联卡片引用并重新检查。生成草稿只使用当前已保存的原文，不会自动保存校对编辑。

批准后的图文卡片可进入练习、APKG 导出和已有 Anki 插件同步。新采纳的推荐图片保存后会进入机审；通过自动批准，有疑点才留在待处理。演示材料或自动检查无法覆盖的卡片可使用备用人工批准入口。

制卡在后台按批执行，显示目标张数、实际生成张数及批次进度。指定张数是目标上限，材料不足或重复内容被过滤时，可能少于目标；系统不自动补请求凑数。目标太少无法覆盖完整范围时会先提示。生成过程中可以查看已经保存的卡片；停止只影响后续批次，当前请求可能仍会完成，已生成内容保留。刷新后可查看任务，服务重启后的中断任务不会自动续费重跑。

小屏幕在「制作卡片」和「检查结果」中使用「查看讲义 / 编辑内容 / 卡片预览」三个按钮切换区域。制卡预览展示未保存的编辑；机审检查已保存的版本，练习及导出读取已保存、已批准的版本。

切换卡片或导航页时，未保存内容在当前页面会话内保留；刷新或关闭页面前需要保存。若另一窗口更新了同一卡片，保存会提示版本冲突并保留当前草稿。先复制需要保留的修改，再使用「载入最新版本」重新编辑。

## 在页面中配置模型

进入侧栏「模型设置」：

- 选择「演示模式」或「自配 API」。
- 填写兼容 Chat Completions 的 **Base URL**、服务商给出的模型名称和 API Key。地址不要附加 `/chat/completions`。
- API Key 留空表示保留已有密钥；需要替换时填入新值。勾选「保存时清除已保存的密钥」才会删除旧密钥。更换服务器时需要重新填写或清除密钥。
- 「高级设置」可修改请求超时，范围 1–180 秒。
- 保存后用于后续生成、回答分析和已配置的图片检查，无需再次重启。正在生成或分析时，请等待任务结束再保存设置。

保存设置不会调用模型，也不代表连接或视觉能力已验证。模型是否支持图片输入，仍需按服务商能力选择。当前官方 DeepSeek 的受支持模型请求显式关闭思考模式，覆盖制卡、答题分析、整卡机审、逐页校对和配图检查；其他兼容服务保留其原有请求参数。

配置保存到当前数据目录的 `model-settings.json`；默认是 `data/model-settings.json`。密钥保存在本机配置文件中，**未加密**，不会回显到网页，也不会写入卡片、浏览器存储或导出文件。不要分享该配置文件。尚未在页面保存配置时，项目继续读取现有环境变量 / `.env`；一旦保存，页面配置优先生效。

## 这次范围

已把导入、编辑、配图检查和整卡机审放在同一个入口，保留模型设置、练习和导出各自的入口。图片挖空、Anki 内嵌制卡窗口仍是后续功能。回答分析目前仍以文字原文和评分要点为依据。保存配置或切换预览不调用模型；生成和保存草稿会触发自动机审，见[整卡机审说明](整卡机审使用说明.md)。

## 验证方式

浏览器检查工具使用独立测试目录和端口，禁止真实云端请求，不修改个人数据库：

- `tools/workbench_check.cjs`：编辑、配图、预览、版本冲突、练习显示与多宽度检查。
- `tools/model_settings_check.cjs`：设置保存、密钥处理、状态更新与错误恢复检查。
- Python 的 `tests/test_model_settings.py` 覆盖设置校验、持久化、即时生效、并发保护和卡片版本冲突。

本次离线测试可以验证程序流程；不等于已测试任意模型服务的连接、生成质量或视觉判断准确率。
