# 代码目录指南

AnkiSense 由桌面窗口、本机服务、网页界面和可选的 Anki 插件组成。桌面端复用本机服务和网页；Anki 负责同步后的间隔复习。

## 项目目录

| 位置 | 用途 |
| --- | --- |
| `ankisense/` | Python 服务、数据处理和模型调用 |
| `ankisense/static/` | 网页 HTML、CSS、JavaScript，以及随包的 KaTeX 资源 |
| `desktop/` | Electron 窗口、后端启动管理、Windows 打包和桌面测试 |
| `addons/ankisense_sync/` | 安装到 Anki 中的同步、配对与作答插件 |
| `tests/` | 后端、前端逻辑测试和脱敏固定样例 |
| `tools/` | 按安装、构建、浏览器、测试数据、评估、Anki 分组的开发工具 |
| `examples/` | 自编演示材料、客户端与评估格式示例 |
| `docs/` | 使用、开发和历史文档 |
| `origin/` | 准备本机 Anki 试用环境的入口；Anki 程序与个人资料不提交 |
| `.github/` | CI、Issue 和 PR 模板 |

表中的位置均相对于仓库根目录。

## 后端从哪里读

| 任务 | 主要文件（位于 `ankisense/`） |
| --- | --- |
| HTTP 请求与数据结构 | `app.py`、`schemas.py` |
| SQLite 与数据路径 | `db.py`、`paths.py` |
| 导入 PDF/PPT 与 OCR | `ingest.py`、`presentations.py`、`ocr.py` |
| 来源版本、引用与漏行修复 | `sources.py`、`source_quotes.py`、`quote_recovery.py` |
| 自动制卡任务与进度 | `automatic_import.py`、`automatic_runner.py`、`auto_cards.py`、`job_progress.py` |
| 模型配置与调用 | `model_settings.py`、`model_policy.py`、`llm.py`、`prompts.py`、`model_json.py` |
| 卡片内容审核与学习目标 | `card_auto_review.py`、`card_quality.py`、`reference_check.py`、`learning_policy.py` |
| 配图、裁剪与图片检查 | `media.py`、`figure_recommendations.py`、`figure_vision.py`、`image_auto_review.py` |
| 作答与反馈 | `attempts.py`、`approval.py` |
| 卡片与材料删除 | `card_deletion.py` |
| Anki 配对、同步与导出 | `anki_setup.py`、`plugin_api.py`、`plugin_sync.py`、`apkg.py`、`downloads.py` |

接口字段以实际模型和路由为准；详细交接规则见[协作接口契约](协作接口契约.md)。

## 界面与桌面

- `ankisense/static/app.js`：页面状态与主要交互；`automatic.js`：导入任务和卡片结果；`workbench.js`：卡片编辑与预览。
- `ankisense/static/model-settings.js` 与 `anki-setup.js`：模型设置和 Anki 连接向导。
- `ankisense/static/card-filters.js` 与 `math-text.js`：筛选和公式显示。
- `desktop/main.js` 与 `preload.js`：桌面窗口和网页桥接；`backend-health.cjs`：后台版本与健康检查；`anki-integration.cjs`：本机 Anki 安装与配对集成。
- `desktop/build-backend.ps1` 与 `ankisense-backend.spec`：后端冻结；`desktop/package.json`：桌面命令与安装器配置。
- `addons/ankisense_sync/collection_sync.py`：通过 Anki API 写入并维护同步基线；`answer_ui.py`：Anki 内作答窗口。

## 工具怎么找

| 工具名称或类型 | 用途 |
| --- | --- |
| `tools/setup/` | 环境安装脚本与公共 PowerShell 安装函数 |
| `tools/build/build_anki_addon.py` | 构建插件安装文件 |

| `tools/evaluation/` | 样本评估 |
| `tools/anki/` | 连接工具、独立 Anki 运行器和同步验收 |

先阅读脚本参数再运行。默认自动测试使用隔离或模拟数据；真实模型评估与 Anki 集成测试需要各自的环境和材料。

## 哪些是本机产物

`data/`、`.env` 保存本机材料、学习数据和配置；`.venv/`、`node_modules/` 是依赖环境；`.ui-checks/`、`.ui-backups/` 是验收与临时产物；`dist/`、`desktop/dist/` 是构建结果。这些目录由 Git 忽略，克隆仓库时不会带走。源码运行的 `data/` 和安装版用户数据目录是不同位置。

`requirements*.txt` 锁定 Python 依赖，`package*.json` 管理 Node 依赖，`pytest.ini` 配置测试收集。这些文件应保留在当前位置。
