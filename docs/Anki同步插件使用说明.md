# AnkiSense 本机同步插件

这版插件把网页中已批准的图文卡片直接保存到 Anki。PDF 导入、识别、校对和制卡仍在 AnkiSense 网页完成；Anki 内的 PDF 工作台和 AI 回答窗口属于后续功能。

## 开始使用

1. 在项目根目录（包含 `start.ps1` 的文件夹）运行 `.\start.ps1`，保持本机 AnkiSense 服务运行。本说明中的命令均从项目根目录执行。
2. 按 [Anki 本地试用说明](../origin/Anki本地试用说明.md) 准备程序和独立资料，然后在项目根目录运行 `.\origin\启动Anki.ps1`。也可以在自己原有的 Anki 资料中按下文手动安装插件。若安装插件时 Anki 已经打开，请正常退出后重新打开。
3. 在 Anki 顶部菜单选择 **工具 → AnkiSense · 同步卡片…**。
4. 在同步窗口选择当前项目的 `data/plugin-connection.json`，再点击 **检查连接**。使用自定义数据目录时，选择该目录里的同名文件。如果文件尚未生成，按下方“连接失败时”的命令初始化。不用复制或粘贴密钥；每台电脑单独选择，移动项目或数据目录后也需重新选择。
5. 选择 **新增卡片的目标牌组**，或点击 **新建牌组…**。第一次试用建议新建“AnkiSense 试用”。
6. 点击 **同步已批准卡片**。完成后关闭同步窗口，打开目标牌组开始复习。

后续在网页修改并批准卡片后，再同步一次即可。已有卡片保持原来的牌组和复习进度。题目配图显示在正面，答案配图显示在背面；图片实际保存到 Anki 的媒体目录，关闭 AnkiSense 服务后仍能正常查看和复习。

卡片上原有的“用自己的话回答”链接仍会打开 AnkiSense 网页，需要本机服务运行。这一版没有把回答输入窗口迁入 Anki。

## 看懂同步结果

| 提示 | 含义 |
|---|---|
| 新增 | 这张卡片首次进入当前 Anki 资料 |
| 更新 | 已同步卡片的内容有变化，更新原笔记，保留复习状态 |
| 未变化 | 已是当前内容，不重复新建；缺失但可恢复的配图会补齐 |
| 冲突 | Anki 中手改过内容、模板不一致或存在重复身份，保留 Anki 中的版本，暂不覆盖 |
| 暂不可同步 / 清单缺席 | 卡片未批准、撤销批准、来源过期或配图异常；已有 Anki 笔记保留，需要回到网页核对 |

同步前先下载并校验整批卡片和图片。下载失败时不进入笔记写入阶段。写入阶段如遇磁盘等异常，会停止后续卡片并提示；此前完整写入的卡片保留，可以重新同步。未引用的新图片可通过 Anki 的“检查媒体”清理。

首版同步当前服务中的全部可用已批准卡片；单次上限 500 张、配图合计 64 MB。同步本身不调用 AI，不发送讲义或回答到云端。

## 已经通过 APKG 导入过怎么办

插件沿用相同的卡片 GUID、NoteID、8 个字段和笔记类型，避免把同一卡片重新创建一份。首次关联时，已有 APKG 笔记只有与服务端内容完全一致才会被接管；如果不同，窗口列出冲突，不猜测哪一份是最新版本。

插件不会自动删除笔记，也不会移动已有卡片的牌组。Anki 中自行添加的标签会保留。同步后可使用 Anki 的撤销功能；撤销或手动删除之后再同步，插件会保守提示冲突，不悄悄恢复你刚删除的内容。

## 连接失败时

- **无法连接**：确认 AnkiSense 已启动，并在浏览器中检查 `http://127.0.0.1:8765`。
- **凭据失效 / 连接禁用**：在项目目录运行 `.venv\Scripts\python.exe tools\plugin_connection.py init`，再选择当前连接文件。
- **没有可同步卡片**：先在网页中完成校对、保存并批准卡片。原文修改后，受影响卡片需要重新审核。
- **存在冲突**：先对照 Anki 与网页中的内容、来源和模板核对。此版没有强制覆盖按钮，不要直接删除自己的学习数据来处理冲突。

连接文件包含本机访问凭据，请勿分享。插件只在本机保存连接文件路径；云端模型密钥继续由后端管理。

## 文件与安装

- 可安装包：构建后生成 `dist/AnkiSense-Sync.ankiaddon`，在自己 Anki 的“工具 → 插件 → 从文件安装”中选择它。
- 本项目本地试用版的插件位置：`origin/AnkiData/addons21/ankisense_sync/`。其他 Anki 安装使用其自己的插件目录，不必复制这份个人资料。
- 源码：`addons/ankisense_sync/`；复用客户端：`examples/anki_plugin_client.py`。
- 每个 Anki 资料独立保存连接标识和目标牌组；同步映射位于该资料目录的 `ankisense-sync-state.json`。备份 Anki 资料时一并保留。
- 协议说明：[插件接口说明](插件接口说明.md)。

先从项目根目录构建安装包：

```powershell
.\.venv\Scripts\python.exe tools\build_anki_addon.py
```

使用本项目 `origin/AnkiData/` 本地试用资料时，也可以构建并安装到该目录：

```powershell
.\.venv\Scripts\python.exe tools\build_anki_addon.py --install-to origin\AnkiData\addons21 --connection-file data\plugin-connection.json
```

构建不会将连接凭据、讲义、学习记录或云端密钥打入插件包。安装只更新本插件文件，不改动学习数据库；更新已有插件时会在 `dist/installation-backups/` 备份被替换的文件。

`--connection-file` 安装参数会在本机记录解析后的完整路径，供独立运行的 Anki 使用。这是本机设置，不属于可共享的项目配置；移动文件后在同步窗口重新选择即可。
