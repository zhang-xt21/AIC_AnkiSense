# 导入导出参考

优先使用网页的 APKG 导出，或安装 [AnkiSense 同步插件](Anki同步插件使用说明.md)。下面保留重复导入和其他格式的详细说明。

## APKG

在「导出至 Anki」下载 `ankisense-approved.apkg`，打开 Anki 的「导入文件」并选择它。题目、答案、配图、来源和样式一起导入，自动建立 `AnkiSense` 牌组和专用笔记类型。

APKG 只包含已批准且来源仍有效的卡片；空集合、缺失或损坏的图片会返回错误。题目配图显示在正面，答案与答案侧配图在背面。卡片的「用自己的话回答」链接指向本机 AnkiSense 服务，其他设备不能直接使用该本机地址。

GUID 由稳定卡片 ID 生成，修改题目或答案不改变身份。修改并批准后再次导入，可更新原笔记。默认按修改时间判断新旧；同秒导出的修改或 Anki 内较新的编辑可能不会被覆盖。需要以网页内容为准时，把更新笔记设为「始终」，这也会覆盖直接在 Anki 内修改的字段。

为保留 Anki 的复习进度，不要启用「导入任何学习进度」，不要手动改变专用笔记类型的字段结构。此前 TSV 导入的笔记与 APKG 笔记不会自动合并，首次切换可能出现重复内容。

本地 genanki 生成导出包，不调用云端模型，也不写入正在使用的 Anki 学习库。接口为 `GET /api/export/apkg`，包大小上限 50 MiB。重要版本更新后，应在独立的 Anki 测试牌组重新验证导入和重复导入。

## TSV 与图文 ZIP

导出页「其他格式」提供 UTF-8 TSV 和含图片的 ZIP，同样只导出已批准卡片。新建独立笔记类型，按以下顺序建立字段，第一字段必须是 `NoteID`：

| 字段 | 内容 |
| --- | --- |
| NoteID | 稳定编号，重复导入时匹配更新；不是 Anki 内部 GUID |
| Question | 问题 |
| Answer | 参考答案 |
| Concept | 知识点 |
| SourceFile | 原始材料名称 |
| PDFPage | PDF 物理页码；演示与粘贴文本留空 |
| SourceQuote | 原文引用 |
| PracticeURL | 本机练习地址 |

正面模板：

```html
{{Question}}
```

背面模板：

```html
{{FrontSide}}
<hr id="answer">
{{Answer}}
<hr>
{{Concept}}<br>
{{SourceFile}} {{PDFPage}}<br>
{{SourceQuote}}
```

导入时选择对应笔记类型与测试牌组，分隔符选 Tab，核对字段映射。纯文本 TSV 关闭「允许字段包含 HTML」；图片 ZIP 内的 TSV 启用 HTML。重新导入时选择更新已有笔记，保持 `NoteID` 和笔记类型不变。

图片 ZIP 先解压，把 `media/` 中的 PNG 直接复制到当前 Anki 资料的 `collection.media`，不复制子目录、不重命名图片，再导入 TSV。题目配图已写入 `Question`，答案配图已写入 `Answer`，包内附导入说明。`/api/export` 提供纯文本，`/api/export/media` 提供图片包。

Anki 的字段匹配和媒体导入选项见 [官方文本导入说明](https://docs.ankiweb.net/importing/text-files.html) 与 [字段模板说明](https://docs.ankiweb.net/templates/fields.html)。TSV / ZIP 的完整桌面操作流程需要单独验证。
