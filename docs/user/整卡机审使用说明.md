# 整卡机审与自动批准

配置云端模型后，生成或保存卡片草稿会自动排队检查。无配图时检查题目、参考答案、评分要点和已引用原文；有配图时先检查需要更新结论的图片，再检查文字。通过后卡片显示「机器审核通过」，可直接练习、导出或同步至 Anki，无需逐页确认或再点击人工批准。

生成和保存按钮旁会说明发送范围：文字检查发送题目、答案、评分要点和引用；图片检查还会发送裁图与对应 PDF 原页，消耗配置的 API 额度。每批最多同时处理两张卡片。普通浏览与 GET 读取进度不会调用模型；失败不会自动重复扣费，需主动重试。服务重启会把未完成的任务标为中断，不自动恢复云端调用。

## 哪些卡片会通过

本机先验证 PDF、当前非空原文、逐字引用和卡片版本；模型逐项判断问题是否可由材料回答、答案是否得到引用支持，以及所有评分要点是否有依据。配图需要当前有效的独立机审通过记录。原文状态为待校对本身不再阻止检查，但空白、识别失败、过期引用仍不能通过。

演示材料、粘贴文字、无法确认来源的图、复杂或有疑点的裁图，目前不在自动批准范围内。它们会给出原因，允许修改后重新检查，也保留人工核对批准作为备用操作。人工批准同样不要求先逐页确认原文。

## 结果与修改

机审会先写出带逐字依据的「最短充分答案」，再检查每条评分要点是否属于题目必答范围。要点即使有原文支持，也可能只是背景：例如只问鸦片战争为何是近代史起点，不应额外强制学生回答条约名称或排名。`scope=background`、题目要求覆盖不完整或无法确认时，均不能自动通过。疑似缺项列表、断句等信号也会随原文交给审核模型，避免用一部分内容冒充完整原因。

升级审核规则后，旧规则下的机器通过记录需重新检查，界面显示为待处理；打开页面不会自动调用模型。历史原文、卡片内容和作答记录保留。人工批准记录不因本次规则升级自动改变。

- **机器审核通过**：服务端原子保存机审记录和 `approval.method=machine`，仅批准状态变化不会增加内容版本。
- **待处理**：显示缺失依据、配图问题、模型失败等具体原因；卡片保留为草稿。
- **人工批准**：记录 `approval.method=human`，与机器批准分开显示。

保存卡片编辑会产生新版本并重新检查；真实修改原文或重新 OCR 会使关联卡片退回草稿，旧批准失效。未改变文字的原文保存保留版本与有效结论。练习、导出、同步不仅检查批准标记，还验证当前卡片、来源及图片与存档机审记录相符；客户端不能仅提交一个机器批准标记绕过检查。

旧版本的「机审通过但未批准」记录不会因打开页面直接批准，需主动重新检查。历史练习快照保留。

机器批准代表满足当前规则，不保证语义零错误，也不能发现所有 OCR 错字。离线模拟测试验证的是流程、版本和失败处理；实际错放率仍需用人工标注讲义测量。学习时仍可展开引用回到原文核对。
