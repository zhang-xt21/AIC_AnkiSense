# 演示指南

建议分两段演示：先用自编材料体验无需 API 的流程，再用少量材料展示真实模型制卡。两种模式分开介绍，不把预设反馈当作模型输出。

## 准备

1. 按[首页](../../README.md#快速试用)启动；首次推荐使用新的学习空间，不迁移个人资料。
2. 自编材料见[栈与队列](../../examples/栈与队列_自编演示讲义.md)。应用内「导入演示材料」会载入同主题示例，无需把 Markdown 当作 PDF 上传。
3. 如需演示 Anki，单独安装 Anki，准备测试资料和测试牌组，再按[插件说明](Anki同步插件使用说明.md)配对。

## 无密钥流程

| 步骤 | 操作 | 观察点 |
| --- | --- | --- |
| 载入材料 | 演示模式下进入「学习材料」，点击「导入演示材料」 | 出现自编讲义及演示卡片 |
| 查看与核对 | 进入制卡工作台，查看题目、参考答案、评分要点及引用；在检查区使用人工核对入口批准所需卡片 | 卡片内容能对应原文；演示卡不进行云端机审 |
| 作答 | 进入「开始练习」，选择栈的顺序题，输入「后进先出」 | 查看本地规则反馈与引用 |
| 尝试遗漏或错误 | 按下表示例重新作答 | 反馈分支不同；这是规则演示 |
| 导出 | 进入「导出至 Anki」，下载可学习卡片的 APKG | 已核对卡片进入导出，文件可由 Anki 导入 |

| 题目 | 示例回答 | 预期分支 |
| --- | --- | --- |
| 栈的出入顺序 | 后进先出 | 正确 |
| 栈的出入顺序 | 先进先出 | 需要修正 |
| 空栈能否直接出栈 | 不能 | 还不完整 |
| 任意题目 | 留空 | 未作答，不调用模型 |

实际反馈以当前版本为准。本地规则支持有限表达，不能用来判断模型准确率。

## 真实自动制卡流程

1. 在模型设置中保存自己的接口、模型名称和密钥，主动点击验证连接。模型需支持所用图片输入格式；不要在录屏中展开密钥或配置文件。
2. 准备自己编写或有权使用的短 PDF，先选少量页面、少量卡片。可将自编讲义另行排版成 PDF；仓库当前提供的是 Markdown 原文。
3. 导入后查看自动任务和生成结果。展开一张卡片的来源，对照题目、答案及配图。
4. 如有未完成批次，展示具体原因和有效卡片已保留的状态；需要重试时主动执行，不用反复点击。
5. 选一张可学习卡片，依次用完整回答和部分回答展示诊断，回看原文依据。

真实请求会发送相关材料并消耗模型额度。演示时记录模型、材料范围和版本；只报告实际看到的结果，不预设一定通过。

## 可选：Anki 复习

保持 AnkiSense 运行，在 Anki「工具 → AnkiSense · 同步卡片」检查连接并同步到测试牌组。再次同步时观察新增、更新和未变化计数。打开已关联卡片，点击「在 Anki 内作答」。反馈后，由使用者自行选择 Anki 的复习评分。

APKG 导入和插件关联是两个步骤。如果出现“尚未安全关联”提示，先完成插件同步并核对冲突；不要把该提示解释为模型连接失败。Anki 首页的新卡数字受每日学习设置影响，不代表全部卡片数量，可在浏览器中查看测试牌组。
