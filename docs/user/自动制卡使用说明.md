# 导入讲义，自动得到卡牌

先在「模型设置」保存云端 API 地址、模型名和 API Key。自动制卡需要模型支持图片输入；目前已用 DeepSeek 开放平台的 deepseek-flash 实测。

1. 打开「学习材料」，在顶部「导入讲义，自动得到卡牌」选择 PPT、PPTX 或 PDF 文件。
2. 选择完成后立即上传并开始处理，页面自动进入「卡牌结果」。无需点击开始制卡、选择片段、确认原文或逐张批准。
3. 等待卡牌陆续出现。点开「显示答案」阅读答案和引用的讲义原页；通过自动检查的卡牌可以直接练习或导出至 Anki。

整份讲义最多 500 页、50 MB，一次最多保存 600 张卡牌。PPT / PPTX 通过本机 PowerPoint 或 LibreOffice 转换，以保留原页图表；PPTX 同时提取原生文字。PDF 自动选择文字层或本机 OCR。转换失败时会显示原因，也可以改用 PDF。

系统自动跳过目录、课程安排和单独的视频文件名；提取知识后生成问答，再通过单独的模型调用对照讲义原页检查答案、评分要点及引用。原页图片附在答案侧，属于来源图片，不表示已经选出或裁剪出唯一的概念配图。文字和原页都会发送至已配置的模型。

有疑点的卡牌会自动尝试修正并重新检查。仍未解决时，卡牌保留「有疑点」说明，其他内容继续处理。此类卡牌可阅读和编辑，但不会作为已就绪卡牌进入练习或导出。个别页面或候选失败会继续其他内容；若模型连接、超时或服务不可用连续发生，则停止后续请求。密钥权限、接口配置或额度限制错误立即停止。界面显示原因、已保留数量和「检查模型设置」入口，重复的处理说明按原因合并。

处理中可点击「取消处理」，上传文件和已保存卡片保留，后续模型请求停止。当前页的本地识别或转换可能仍在结束；已发送的远端请求无法撤回，也不保证服务商停止计费。之后点击「继续未完成部分」可补跑；自动任务允许在明确继续前修正模型配置，已完成的卡片不重复生成。

任务和卡牌保存在本机。切换页面不会取消任务；刷新页面会继续显示结果。服务重启后，未完成任务标为「已中断」，由用户点击继续处理，不自动发起新的付费请求。相同文件重复选择会返回原任务；失败或中断时可补跑，已经保存的卡牌不会重复生成。原文被修改后，引用旧版本的卡牌会失效，旧自动检查不能用于新内容。

「已自动检查」表示当前版本通过了模型与原页检查，不表示经过人工审核，也不能保证模型不会漏错。页面原文的「待校对」状态与卡牌检查分别记录：不要求先把整页标成人工确认，才能得到卡牌。

系统先按材料建议张数，也可在导入高级选项中指定 1–600 张并选择是否附讲义原页；材料不足时允许少于目标数量。需要自行修改时，在卡牌结果中点「编辑卡牌」，或展开「学习材料」底部的「高级工具：检查原文与补充制卡（可选）」。补充制卡可指定片段，每次后台任务支持 1–30 张；旧单批接口限 1–6 张。

开发验收使用 `tests/test_automatic_import.py`、`tests/test_auto_card_ai.py` 和 `tools/browser/automatic_import_check.cjs`。有界真实模型实测工具是 `tools/evaluation/evaluate_automatic_cards.py`，实测须使用已配置模型并会产生 API 用量；离线测试不调用真实模型。
