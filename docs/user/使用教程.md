# AnkiSense 使用教程：从第一次打开到接入真实课程

本教程适用于已经安装好依赖的 AnkiSense 项目。新电脑或移动后的项目请先按 [README 的启动说明](../../README.md#启动)创建 Python 环境；完成后日常使用不需要重复安装。

建议先完成一次演示，再准备自己的「数据结构：栈与队列」讲义，最后接入真实 AI。演示阶段不需要 API Key，也不需要安装 Anki。

## 1. 先认识几个名字

| 名字 | 在这里是什么意思 |
| --- | --- |
| AnkiSense | 我们正在搭建的项目：从讲义制作题目、审核、作答并查看反馈。 |
| PowerShell | Windows 中输入命令的窗口。这里用它启动和停止项目。 |
| 本地服务 | 在你电脑上运行、负责保存材料和处理请求的程序。网页打开期间要让它保持运行。 |
| 浏览器 | Edge、Chrome 等平时打开网页的软件。AnkiSense 的界面在浏览器里显示。 |
| 演示模式 | 使用项目自带材料和固定规则体验流程，不调用大模型。 |
| 云端模式 | 本地服务通过 API 生成题目、自动检查保存后的卡片、分析回答，也可按需辅助逐页校对。 |
| API Key | 模型平台发给你的调用密钥，类似程序访问服务的通行证。 |
| Anki | 另一个独立的记忆卡片软件，可用于安排复习；当前用 AnkiSense 不必先安装它。 |

## 2. 打开 AnkiSense

### 第一步：打开 PowerShell

在资源管理器打开项目根目录，也就是包含 `README.md` 和 `start.ps1` 的文件夹。在地址栏输入：

```text
powershell
```

然后按回车。这样打开的 PowerShell 已位于项目根目录。接下来的命令要粘贴到这个窗口里，不是浏览器地址栏；项目可以放在任意盘符或目录。

### 第二步：启动本地服务

从项目根目录复制执行下面的命令：

```powershell
.\.venv\Scripts\python.exe -m uvicorn ankisense.app:app --host 127.0.0.1 --port 8765
```

看到类似下面这一行，就表示服务已启动：

```text
Uvicorn running on http://127.0.0.1:8765 (Press CTRL+C to quit)
```

窗口停在这里、没有重新出现输入提示，是正常现象。**让窗口保持打开，可以最小化。**不要在这个仍在运行的窗口中接着输入别的命令。

### 第三步：打开网页

打开 Edge 或 Chrome，在地址栏输入：

<http://127.0.0.1:8765>

这是当前电脑上的地址。浏览器出现 AnkiSense 学习工作台后，即可操作。

第一次体验前看一下右上角：本教程下一节对应 **「演示模式 · 本地规则反馈」**。如果你已经切换过云端模式，按 [AI 接入指南](AI接入指南.md)中的方法切回演示并重启，或直接阅读本教程的真实讲义部分。

### 用完后怎样关闭

先回到运行服务的 PowerShell 窗口，按 **Ctrl + C**，等服务停止后再关闭窗口。下次使用，在项目根目录打开 PowerShell，重新执行上面的启动命令即可。

已经保存的讲义、审核结果和练习记录会留在项目的本地数据库中。练习答案草稿可在同一浏览器标签页切换、刷新后继续；关闭标签页后不保证保留，重要内容请先提交或另行保存。

## 3. 页面上的三个主要入口

左侧导航按使用顺序排列：

| 入口 | 你在这里做什么 |
| --- | --- |
| 讲义制卡 | 按「导入讲义 → 制作卡片 → 检查结果」三步操作；自动检查通过即可学习，有疑点时再处理。 |
| 开始练习 | 选择已批准的题目，输入答案并查看反馈。 |
| 导出至 Anki | 下载已批准卡片的 APKG 牌组包，连同配图和样式直接导入 Anki。 |

「模型设置」在侧栏单独提供。三步可以在同一个「讲义制卡」入口内切换。配置云端模型后，真实 PDF 的新卡片和保存后的草稿会自动排队检查；题目、答案、引用及必要配图全部通过后，显示 **「机器审核通过」**并进入可学习状态，无需逐页确认或再点批准。有疑点或检查失败时显示「待处理」，可修改后重新检查；演示、粘贴文本等暂不在自动批准范围，可使用「人工核对并批准」作为备用入口。基础题和补充练习分别检查。

生成或保存后触发的自动检查会将相关文字、必要配图及其原页发送给当前配置的模型 API，消耗 API 额度。上传讲义或打开卡片本身不会自动进行整篇 AI 校对；自动检查也可能出错，可随时查看来源和检查结果。

## 4. 先完整体验一次演示

### 4.1 导入自编示例

在「讲义制卡 → 导入讲义」点击 **「导入演示材料」**。

第一次导入会得到「栈与队列 · 自编演示讲义」和 **6 张待审核草稿**：3 张基础卡片、3 张补充练习。它们由项目预先编写，不是 AI 当场生成，也不是你们实际课程的讲义。

再次点击这个按钮不会再增加一套相同卡片，也不会重置已有的审核或编辑结果。已经用过演示时，看到部分卡片为「已批准」是正常的。

### 4.2 批准基础题和对应补练

在「讲义制卡」选择 **「检查结果」**。依次选择下面的题目，对照左侧讲义原文检查后，点击 **「人工核对并批准」**。自编演示材料不是机审所需的真实 PDF，仍由你人工核对。

| 基础题 | 对应的补充练习 |
| --- | --- |
| 栈的出入顺序规则是什么？ | A、B、C 依次入栈后，第一次出栈的是谁？请说明理由。 |
| 队列的出入顺序规则是什么？ | A、B、C 依次入队后，第一次出队的是谁？请说明理由。 |
| 空栈能直接执行出栈吗？为什么？ | 程序在弹出栈顶元素之前，应先检查什么？空栈时应如何处理？ |

为了按下面的步骤复现反馈，首次体验时可把这 6 张都核对并批准。只批准基础题时可以正常作答，但系统可能找不到可推荐的补练。

**本轮演示只改变审核状态，保留原始问题、参考答案、概念、用途、评分要点和引用内容。**演示规则只支持未经修改的内置基础题；修改这些内容后，即使答案看起来正确，也可能显示「暂时无法判断」。真实课程的修改与审核在接通云端模型后进行。

「检查结果」中的其他按钮含义是：

- **保存并检查**：保留编辑；云端模式会自动检查，通过后进入练习或导出。演示模式只保存，不调用模型。
- **拒绝**：标记当前卡片不采用，它也不会进入练习或导出。
- **人工核对并批准**：人工核对后保存并允许练习、导出，作为异常或不支持自动批准材料的备用操作。

### 4.3 试出四种反馈

点击 **「开始练习」**，在「当前练习」下拉框选择题目，将表格中的文字原样填进「你的回答」，再点击 **「提交回答并分析」**。

每次查看完结果，点击 **「重新作答」**，或切换到下一道题，再试下一行。以下结果仅对应当前演示规则和未经修改的内置基础题。

| 选择的题目 | 在回答框中输入 | 预期显示 |
| --- | --- | --- |
| 栈的出入顺序规则是什么？ | `后进先出` | 回答正确 |
| 空栈能直接执行出栈吗？为什么？ | `不能` | 还不完整 |
| 栈的出入顺序规则是什么？ | `先进先出` | 需要修正 |
| 栈的出入顺序规则是什么？ | `我还没想清楚` | 暂时无法判断 |

再试一次**清空回答框后提交**：页面会显示「你还没有填写回答」，记录为「未作答」，不会算成回答错误，也不会调用 AI。

「暂时无法判断」表示当前规则无法可靠判断这段表达，不是「一定答错」。即使另一种说法在知识上正确，只要没有被演示规则覆盖，也可能得到这个结果。上表用来检查页面流程，不能用来证明 AI 的诊断能力或教学效果。

### 4.4 看依据和补练

提交后，在右侧「本次反馈」查看判断理由、需要补充或修正的要点，以及「回到原文核对」。也可以展开 **「查看已审核的参考答案」**。

回答不完整或有明确错误时，如果已经批准对应补练，并且还没有作答过该补练，页面可能显示 **「针对这个知识点，再试一题」**。点击 **「去做补充练习」**即可打开。

当前演示支持补练的推荐与打开，但**没有为补练答案编写完整诊断规则**。在演示模式给补练作答，通常会得到「暂时无法判断」；接通云端模型后才能体验它的真实分析。补练已经作答过时不会重复推荐，仍可在「当前练习」下拉框主动选择。

页面右侧「最近练习」显示最近保存的记录。点击一条记录可以查看当时的回答和反馈。

### 4.5 按进度连续练习

练习页顶部显示进度条和 **「全部」「未完成」「已完成」** 三个分类，数量只统计当前已批准的卡片。先选「未完成」，再用回答框下方的 **「上一张」「下一张」** 连续切换，也可以直接从下拉框选题。页面会显示当前分类中的位置；到最后一张时提示「已到最后一张」，并停用下一张按钮。

**已完成表示当前版本至少有一次非空回答收到有效分析结果，不等于答对。**「回答正确」「还不完整」「需要修正」「暂时无法判断」都算完成一次练习；空白未作答、分析中和分析失败不算。同一版本完成过后，再次空白提交或分析失败，也不会抹去已有的完成状态。

在「未完成」中提交成功后，当前题目和反馈会继续保留，先看完再点「下一张」。如果后面的题目已做完，会继续找前面跳过的未完成卡片。全部完成时，页面提示「本组练习已完成」，可以切到「已完成」回看反馈或重新作答。

写了一半的答案会按卡片和版本暂存在**当前浏览器标签页**，切换题目或刷新后，重新选中该卡片即可继续。草稿不计入完成进度，也不会自动提交给 AI。「重新作答」会清空该卡片的草稿供你重写，已保存的练习记录仍保留。

审核保存导致卡片版本更新后，需要针对新版本重新练习，新版本会显示「未完成」。以前的回答和反馈仍可在「最近练习」查看，并标注为历史版本；旧版本的草稿也不会自动填入新题。

### 4.6 给卡片加入讲义配图

在「讲义制卡 → 制作卡片」选中一张卡片，找到 **「讲义配图」**：

1. 上传电脑里的讲义截图（PNG、JPEG、WebP，每张最多 5 MiB，每卡最多 4 张）；也可选择这张卡片所属 PDF 已导入的页面，附加整页原图。文本或演示材料没有 PDF 原图时，使用截图上传。
2. 为图片选择显示位置。**题目侧**用于看图作答；**答案侧**用于答题后讲解，新增图片默认采用答案侧，避免整页讲义提前暴露答案。
3. 可填写图片说明、调整顺序或移除图片。点击 **「保存并检查」**后，配图才正式保存到卡片，并在云端模式下进入自动检查。
4. 到「检查结果」查看进度。系统先检查必要配图，再检查整卡内容；全部通过自动批准。有疑点的图片可重裁、更换或移除，也可人工核对后批准。
5. 练习时可点击图片查看大图；提交非空答案并收到分析结果后，展开「查看已审核的参考答案」可看答案配图。空白提交、分析失败不会显示答案配图。

当前 AI 仍按**文字题目、评分要点和原文**分析，不会识别配图。图中解题必需的条件要写入题干，正确结论要写入评分要点。例如题目图展示 A、B、C 入栈，题干仍需说明入栈顺序。

图片文件保存在本机，替换或移除卡片配图不会改写历史答题时的图片。审核保存后卡片版本更新，练习完成状态按新版本重新统计。

## 5. 换成自己的「栈与队列」讲义

可以先导入材料，再接入 AI。当前演示模式允许导入和查看原文，但不能据此生成真实课程的新卡片。

### 方式一：上传 PDF

1. 在「讲义制卡 → 导入讲义」点击 **「＋ 导入新讲义」**，再选择 **「上传 PDF」**。第一次使用时，导入区会直接显示。
2. 选择讲义文件。第一批建议用一章约 10–20 页，文件不超过 **10 MB**。
3. 按需要填写「起始页」和「结束页」，一次选择最多 **30 页**。长讲义不要留空后直接导入全部页。
4. 识别方式保持 **「自动识别」**，点击导入。扫描页会在本机 OCR，可能需要数秒至数分钟；原有文字页直接提取。
5. 查看系统建议的制卡张数，也可调整为 1–30 张，然后点击「开始制卡」。默认使用本次导入的全部有效原文，无需逐段勾选或逐页确认；识别失败或没有文字的页面会提示跳过，可重新识别或补入文字。
6. 需要核对时打开 **「检查原文」**，也可从卡片左侧点击 **「检查第 N 页原文」**。对照原图检查文字、公式、符号和顺序，修改后点击 **「保存原文」**。这是可选的修正入口，不是批准卡片的前置条件。已配置支持图片输入的模型时，可主动点击 **「AI 校对当前页」** 获得建议和疑点。

页码按 PDF 的**实际页序**计数，从第一张页面开始数，封面也算一页。例如某页正文印着「第 1 页」，但前面有封面和目录，那么要按 PDF 阅读器显示的页序填写，不一定填 1。

已支持把扫描图片中的印刷中英文识别成文字。OCR 在本机运行，不需要另配 API Key；新版依赖需要安装 `requirements.lock.txt`。识别内容仍可能出错，尤其是上下标、公式、表格和图中的关系；发现疑问时可对照原图修正，不要求每页人工确认。

原文检查默认折叠，不会在导入或制卡时自动进行整篇 AI 校对。需要批量检查时，展开后点击 **「AI 检查未人工核对的 N 页」**：界面会先说明发送范围，再逐页向当前配置的视觉模型发送原页 PNG 和该页当前已保存文字，每页一次，失败不自动重试。结果会显示「当前已保存原文」「AI 建议文字」和疑点；你选择 **「将建议填入编辑框」** 后仍可修改，再手工保存。已有未保存修改不会被建议覆盖，也不会被生成草稿隐式采用。详细操作见 [OCR 与校对](OCR与校对使用说明.md)。

自动识别漏字时，可在该页点击重新 OCR，也可以导入时选择全部 OCR。识别失败或没有文字时仍保留 PDF 原图，可以重试或手工录入。「查看原始识别文字」保留未校对结果。只确认而未改文字时保留版本和已有卡片；实际修改或重新 OCR 会创建新版本，让引用旧版原文的卡片退回待审核，需重新生成或更新引用后批准；以前的回答和引用不会被改写。

切换校对页时未保存文字会留在当前浏览器标签页。如果其他操作更新了同一页，保存会提示版本冲突，先对照最新版本再继续，避免覆盖别的修改。原有旧 PDF 材料可重新导入以启用逐页校对。

### 方式二：粘贴文本

1. 切到 **「粘贴文本」**。
2. 「材料标题」填写例如「数据结构 · 栈与队列」。
3. 在「课程原文」粘贴讲义中的文字，至少 20 字，保留定义、适用条件和例子。
4. 点击 **「保存课程原文」**，再核对右侧显示的内容。

粘贴文本的页面编号是材料内部的占位编号，不代表原 PDF 的真实页码。

## 6. 接好 AI 后生成、审核和练习

先在侧栏「模型设置」配置服务商地址、模型名称和密钥；页面保存后用于后续请求，无需重启本地服务。细节见 [AI 接入指南](AI接入指南.md)。

右上角出现「云端模式 · 模型名称 · 未验证」只表示程序读到了相应配置。先在「模型设置」保存完整配置，再点击「验证连接」：绿色「验证通过」表示上次文字请求与 JSON 测试成功，红色「验证失败」可在设置页查看原因。每次测试发送一次固定短文本并消耗少量 API 额度，不发送讲义或回答；保存配置或重启服务会恢复未验证状态。图片能力和实际生成、分析效果仍需分别验证。

回到「讲义制卡」后：

1. 在「当前讲义」中选择自己的讲义。
2. 默认使用当前讲义全部有效原文。系统按文字量和范围在本机估算建议张数，不额外调用模型；你可以调整为 1–30 张，或恢复建议。只想针对某段出题时，在高级设置指定原文片段。
3. 点击 **「开始制卡」**。系统分批发送原文并生成草稿，保存后自动排队审核；进度会显示目标与实际张数，可以查看已生成卡片或停止后续批次。材料不足或重复问题被过滤时，可能少于目标，不会自动补请求凑数。目标太少无法覆盖所有范围时会提示。刷新可继续查看进度；服务重启后中断任务不会自动重跑。
4. 第 2 步「制作卡片」中按需修改问题、答案、评分要点、引用和配图，点击 **「保存并检查」**会重新检查当前版本。
5. 第 3 步「检查结果」中查看「等待自动检查」「正在自动检查」「机器审核通过」或「待处理」。通过后即可学习，不必另行批准；有疑点时修改卡片，失败时手动重试。演示、粘贴文本或不符合当前自动批准范围的卡片，可人工核对后使用备用批准入口。
6. 到「开始练习」提交自己的回答，查看模型给出的理由，并对照原文检查是否合理。

生成结果先作为草稿保存，格式正确本身不等于审核通过。只有当前版本通过整卡检查及所需配图检查后才自动批准。机器审核不是正确性保证；初次验证可准备几份明显正确、有遗漏和明确错误的答案，人工检查反馈，当前尚不能据此宣称已验证教学效果。

提交答案时，云端收到当前题目、参考答案、评分要点、相关原文和本次回答。自动检查会发送卡片文字与相关原文；需要检查配图时还会发送最终裁图与对应原页。完整 PDF 在本机解析，不直接整份传给模型；主动进行 AI 校对时，则会逐页发送所选页的 PNG 原图和该页文字。

### 自己课程的补练从哪里来

当前「开始制卡」按基础卡片生成，不会同时自动备齐对应补练。首次可以先完成基础题流程。

要演示真实课程的补练，可从同一份材料再生成一批草稿，由出题者选一张改编为针对性练习，在「制作卡片」将 **「卡片用途」**改为 **「补充练习」**，点击「保存并检查」，到「检查结果」查看是否通过。它需要来自同一份材料，与基础题使用一致的「知识概念」，并保留相关评分要点的相同编号，系统才能把它匹配到对应遗漏或错误。这里的编号可以理解为同一知识点的标签；初次准备时交给项目开发者协助核对即可，无需学习者手动维护。

没有匹配补练时，系统会提示先回顾原文，基础题仍然可以正常练习。

### 分析失败时

如果页面显示「分析暂未完成」，先看具体错误提示。已提交到服务并保存的回答会保留，可点击 **「保留原回答，重试分析」**；同一份失败记录最多重试两次。

「分析失败」和「暂时无法判断」含义不同：前者是调用或结果处理没有完成；后者是收到了一条无法可靠判断的反馈。二者都不应直接解释成你答错了。密钥、接口或额度问题按 AI 接入指南处理后，再重试。

### 为卡片推荐讲义配图

在「讲义制卡 → 制作卡片 → 讲义配图」点击「推荐讲义配图」，查看引用页的图块候选。点击「采纳」加入编辑，或用「预览 / 调整范围」在原页框选局部。找不到图时会提供明确标注的整页原图备选。

新图片默认放在答案侧，已有配图会保留。点击「保存并检查」后，新图片与当前卡片一起检查，通过后自动批准，有疑点才进入待处理。更改题目或引用后请先保存再重新推荐。详细操作见 [自动配图使用说明](自动配图使用说明.md)。

## 7. Anki 是可选的下一步

**Anki 是独立的桌面记忆卡片软件，不是这个网页里的另一个模式。**AnkiSense 负责从材料整理卡片、审核和作答反馈；导出后，可把卡片交给 Anki 安排复习。你暂时没有 Anki，也能完成前面所有步骤。

要导出时：

1. 点击左侧 **「导出至 Anki」**。
2. 查看可导出的已批准卡片数量。
3. 点击 **「下载 … 张卡片 · APKG」**，保存 `ankisense-approved.apkg`。
4. 打开 Anki，点击 **「导入文件」**，选择这个 `.apkg`。无需解压、建立字段或复制图片。
5. 导入完成后进入 **「AnkiSense」** 牌组，开始复习。题目配图在正面，答案与答案配图在翻面后显示。

只有已批准的卡片会进入文件，草稿和已拒绝卡片不会导出。批准过的演示卡片也会一起导出，并保留演示来源标记。配图指审核时已经保存到卡片的图片，导出操作不会自动生成新图片。

**更新已导入卡片**：在 AnkiSense 修改并重新批准后，再下载 APKG 并导入；需要以网页内容为准时，在 Anki 导入选项中把更新笔记设为「始终」，这会覆盖直接在 Anki 内修改的字段。不要启用「导入任何学习进度」。同一卡片保持固定身份，不会因修改题目而自动新增一张。默认按修改时间更新，同秒导出的修改可能被忽略。如果此前用 TSV 导入过这些卡片，APKG 不会自动与旧 TSV 笔记合并，首次切换格式可能出现两份笔记。

**其他格式**：展开「其他格式 · TSV / 图文 ZIP」可继续使用旧流程。TSV 是按列保存文字的文件，导出含 8 列。纯文本 TSV 不包含配图。

Anki 里需要建立匹配的笔记类型和 8 个字段，其中第一字段是 `NoteID`，用来在重复导入时匹配同一卡片。纯文本 TSV 导入时关闭 HTML。图片卡 ZIP 先解压，将 `media` 文件夹中的 PNG 文件直接复制到当前 Anki 配置的 `collection.media` 文件夹，再导入包内 `ankisense-approved.tsv`，**启用「允许字段中使用 HTML」**。不要把整个 `media` 文件夹作为子目录复制，也不要改图片名。ZIP 内附有导入说明。

具体字段顺序、正反面模板和更新已有笔记的步骤，见 [导入导出参考](导入导出参考.md)。首次建议使用单独的测试牌组。

APKG 卡片上的 **「用自己的话回答」** 会打开当前电脑的 AnkiSense 练习页面，需要本机网页服务正在运行；换到手机或其他电脑，不会自动变成可用的公网地址。AI 反馈不会自动替你选择 Anki 的复习评分。

## 8. 常见卡住的地方

| 现象 | 先检查什么 |
| --- | --- |
| 浏览器打不开或显示「本地服务未连接」 | PowerShell 是否还开着，是否出现 Uvicorn 启动成功行，访问地址是否为 `http://127.0.0.1:8765`。 |
| 启动提示端口已被占用 | 可能已经有一个 AnkiSense 在运行，先直接打开上面的地址；不要连续启动多次。若旧服务还开着，在它的窗口按 Ctrl+C 后再启动。 |
| 练习页没有可学习卡片 | 去「讲义制卡 → 检查结果」查看检查是否完成；通过后自动可学习。有疑点或失败时按原因处理。演示、粘贴文本可人工核对后批准。 |
| 「开始制卡」不可点击 | 演示模式不支持生成；请配置云端模型，检查讲义是否有可用原文和有效目标张数。高级范围需至少选一个片段；同一讲义已有任务时先等待或停止。 |
| 演示题总是「暂时无法判断」 | 先用第 4.3 节的题目和原样输入；检查是否改过演示卡片内容，或选到了补练。 |
| 没出现补练按钮 | 对应补练是否已批准、是否匹配知识点、是否已经作答过；「回答正确」本来就不会推荐补练。 |
| 上传后文字缺失或公式不对 | 在逐页校对中对照原图修改，或单页重新 OCR；配置视觉模型后也可主动请求 AI 校对建议。复杂公式、表格和图示仍需手工核对。 |
| 云端出现密钥、权限、超时或额度错误 | 查看 [AI 接入指南](AI接入指南.md)，不要把报错当成答题结论。 |
