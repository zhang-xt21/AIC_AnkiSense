# 讲义原图与卡片配图

基础配图使用 pypdfium2 渲染 PDF 原页、Pillow 裁剪图片，无需另外安装版面模型。

## 添加配图

1. 在制卡工作台保存题目与引用，在「讲义配图」点击「选择原图」。仅准备本卡引用的页面，过程在本机完成。
2. 点击页缩略图，拖动框选范围。需要准确坐标时展开「精确调整范围」。
3. 选择答案侧或题目侧，再点击「加入卡片」。默认答案侧，避免提前显示答案；取消或 Esc 放弃本次框选。
4. 点击「保存并检查」保存卡片。已有图片保留，最多 4 张；也可上传截图，或展开「其他页面」附加完整原页。

不再自动识别独立图块、表格和邻近图注。生成流程可在本机提前准备引用页供裁剪；不会为寻找图块而调用模型，也不会把整页自动当作题图。现有自动导入流程的答案侧原页配图继续保留。

## 图片检查

在裁剪弹窗点击「检查配图」，直接使用模型设置中的地址、模型名和密钥。请求包含当前最终裁图、对应完整原页，以及已保存的问题、答案、评分要点和引用文字，会消耗 API 额度。模型须支持图片输入与 JSON 输出；文字连接验证不能证明图片能力可用。

检查显示关系、完整性、清晰度和题目侧答案泄露等结论，详细信息折叠显示。未缓存的检查只请求一次，不跟随重定向；失败后由用户主动重试。打开弹窗、准备原图与读取状态不调用模型。改变裁剪范围、显示位置、卡片内容或模型后不会沿用旧结果。

保存的讲义裁图会先核对来源页、原文版本、PDF 指纹及实际 PNG 是否与裁剪范围一致，再做视觉检查。单张图通过不会直接批准整张卡片，仍需题目、答案、评分要点和引用全部通过整卡审核。上传图片缺少可验证的讲义来源时，可使用人工核对入口。

## 历史数据与 Anki

已有图片、讲义页码、裁剪范围与旧任务记录保留。新检查使用新的版本标识，旧机审结果不能替代当前版本检查。原文或图片变化后需要重新检查。

批准后的图文卡片可练习、导出 APKG 或同步到 Anki；图片复制到 Anki 媒体目录。Anki 插件不依赖版面解析组件。

## 0.1.15 配图审核规则

裁剪预检与保存后的配图审核使用同一套规则。示意图、表格、统计图、公式、照片及文字截图（包括完整讲义页）均可参加机审；只有来源可验证、与题答相关、必要内容完整、实际图片清晰时才通过。装饰图、未知类别或关键判断不确定不会自动通过。

答案侧在答题后显示，包含答案文字本身不算泄题；题目侧还须确认没有提前显示答案。把图片从答案侧移到题目侧后，需要保存并重新检查。来源疑点、裁切缺失、模糊和无关内容仍会阻止放行。

“配图待核对”表示检查已完成但尚有疑点，不表示仍在排队。自动生成的答案侧原页与保存的讲义裁图均可按此规则检查；没有可验证来源的手动上传图片仍需人工核对。单张配图通过不等于整张卡片通过。

本次规则和提示词升级会使旧配图审核凭证失效，历史记录保留。打开页面或读取状态不会自动请求模型；需要重新检查当前版本，检查会消耗已配置模型的额度。图文整卡审核也必须使用当前有效的配图凭证。
