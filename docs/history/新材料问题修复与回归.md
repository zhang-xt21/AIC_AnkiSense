# 新材料问题修复与回归

> 历史记录：保留当时的方案与验证范围，不代表当前版本的完整行为。当前入口见[文档导航](../README.md)。

日期：2026-10-28。针对10月27日四份新材料试验暴露的问题修复，未把开发回归当成新的独立质量评测。

## 审核回执与诊断重试

原页审核明确要求 `reviews -> card_index + review` 包装。某个候选的编号、结构或证据校验失败时，保留同批已验证的回执，携带具体字段错误对原卡片最多定向重试一次。禁止猜测编号、接受重复编号或按裸数组顺序补绑定。

两次仍无效时记录 `review_protocol_error`，保留原草稿，不进入内容改写。可以从卡片重新发起审核。网络、鉴权、额度问题仍走原有服务失败路径。

诊断模型返回结构错误、要点互斥冲突或无效引用时，最多定向重试一次，并传回校验错误。互斥与引用约束不放宽；持续失败不产生有效诊断。反馈不附原始模型输出或密钥。

## 题目范围与评分点

1. 除参考答案自测外，新增一次仅接收题目和本卡引文的独立作答，不发送参考答案与评分点。
2. 再由实际诊断器评价此回答，必须正确、覆盖全部评分点且证据完整，才允许自动放行。记录 `minimal_answer_check`；失败归为 `minimal_answer_mismatch`。
3. 真实回归发现，独立作答仍可能照抄引文中的多余表示法。故另加保守本地规则：评分点明确强制“给出表示(…)”“写出符号表示”等，而题目未要求表示法、符号、公式或表达形式时，保留为待处理。该规则只拦截明确表达要求，不试图判断一般语义质量。
4. 修复不得扩大原问题来保留额外评分条件。对于确实要求公式或符号表示的问题，保留其必要评分点。

这几层检查仍不能证明评分点在所有课程中都最小充分；须保留独立人工评审。

## 数量与恢复

各计划来源先有一次制卡机会，再把空余全局预算分配给已提取、校验通过但因页配额未选的知识点。复用原检查点，不重跑提取，不为凑数补写知识，不突破本次数量上限。

记录 `backfilled_count` 与剩余 `deferred_knowledge`；继续任务不会重复保存已完成卡片。离线复现中，4页分别有1、1、0、4个有效知识点、目标8张，原先只选4个，现在选完6个，保持不足8张的部分完成状态。

## 历史批准与调用影响

自动制卡策略升级至 `automatic-card-visual-v3-minimal-answer`，整卡机审升级至 `whole-card-review-v5-minimal-answer`。缺少当前独立作答检查的旧机器批准需重新检查，才能用于当前程序的学习、导出和同步。不会批量改写或删除用户卡库。

拟自动放行的卡片通常新增两次调用：独立作答一次、诊断一次。审核与诊断的无效结果各最多再定向重试一次，可能增加等待和额度消耗。浏览、状态查询、导出不触发这些付费检查。

## 真实开发回归

- 同一已授权四份材料累计114/120次，本次修复回归新增19次；此前旧六份材料的103次另计。
- 线性表卡修复后，移除未问的符号序列评分要求，题目范围保持不变。原先被扣分的完整同义回答判正确，明确错误回答判错误。
- PPTX原先被拒收的3张候选均取得有效编号绑定回执，分别通过参考答案和独立作答检查。这是候选级回归；本轮没有重跑四份材料的完整导入、制卡及Anki界面验收。
- 首次独立作答检查仍被引文中的冗余表示误导，此中间失败保留；最终本地规则确认能拦住该旧卡，即使模型声称自测正确。
