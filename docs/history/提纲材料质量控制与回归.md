# 提纲材料质量控制与回归

> 历史记录：保留当时的方案与验证范围，不代表当前版本的完整行为。当前入口见[文档导航](../README.md)。

适用于2026-10-27提纲试跑后修复的版本。以下检查约束自动放行；它们不能替代独立人工质量评价。

## 题干条件与评分点

- 制卡与整卡审核区分 `required`（本题必答）、`given`（题干已给）、`background`、`uncertain`。已给条件不能再次作为必答评分点；题目明确要求未给出的适用条件时仍需评分。
- 拟自动放行的卡片须由实际短答诊断器使用参考答案自测，结论为 `correct`、逐项覆盖全部评分点，且引文、答案原文和要点编号均有效。
- 自测失败时自动制卡最多尝试一次修复并重新审核、自测；仍不一致的候选保留为草稿。保存卡片的整卡机审会显示需要处理的原因，不能自动放行。
- 旧卡的评分点若与题干要求冲突，诊断提示依据冲突、建议重新审核，不将此问题归为学生遗漏。

验收样例：题干已经给出 `P(B)≠0`、只问条件概率定义时，公式答案足够；问题明确要求“公式及适用条件”时，遗漏条件仍应判不完整。错误条件仍应判错误，答非所问仍应判无法判断。

## 选材与范围大纲

默认目标为学习学科知识。提取与审核提示词排除课程编码、学分学时、考勤、考核比例、先修课程、课程目标编号、实验安排等管理信息，以及没有具体知识答案的教学重点清单。

程序另对明确的管理信息目标作保守筛选，保留筛除原因和原候选；它不会因页面混有管理内容就删除整页。SQL中统计学分、文件目录结构等学科内容不因出现同名词语而被排除。引用和语义证据校验继续保留。

## 数量与来源覆盖

- 指定数量时先按来源页分批，配额优先分给不同页。目标8张、4个短页面时每页规划2张；单个来源超过6张则安排后续批次，携带此前已提取知识避免重复。
- 后续批次有独立的检查点编号，重试不会把同一来源的不同批次混为一批；旧任务继续使用已有计划，避免更改已完成部分。
- 若前次提取为空或只产生重复候选，后续同来源批次不再反复发起空请求。数量是上限预算，不保证材料一定支持足够多的合格卡片。
- 同批候选优先选择尚未表示的来源页；未选候选、管理信息筛除项、重复数及当前卡片引用页均留存。
- 界面显示未被卡片引用的计划来源页。`source_coverage_ratio` 和兼容字段 `coverage_ratio` 都仅表示来源纳入计划的比例，不是人工确认的知识点覆盖率。

## 历史卡片与调用量

自动制卡及整卡机审的批准策略已升级。没有当前版本参考答案自测记录的旧机器批准，不再作为导出、同步和学习的有效批准；需重新机审。用户人工批准仍按原有来源和版本规则处理。本次代码修改不批量改写或删除用户卡库。

每次拟自动放行增加一次诊断调用；修复后的候选还会再次检查。普通读取状态、浏览结果和导出仍不发起模型请求。

## 验证口径

本轮失败卡片、行政信息样例、数量和检查点问题已进入离线回归。真实模型只对同一批已授权材料作开发性定向回归：审核并修复两张概率卡，检查缺条件、矛盾和离题对照，检查网络大纲提取和史纲未覆盖页的知识提取。原始结果在工作区“作品提交材料准备/05_测试与效果评估”的独立修复记录目录中保存，不覆盖首轮试跑结果。

这些材料已经用于开发。正式评估应另选材料、冻结版本，独立人工标注后计算可用率、覆盖率及审核错放率；人工省时仍需用户对照实验。
