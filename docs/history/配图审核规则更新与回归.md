# 配图审核规则更新与回归（0.1.15）

> 历史记录：保留当时的方案与验证范围，不代表当前版本的完整行为。当前入口见[文档导航](../README.md)。

构建日期：2026-10-28，Windows x64。安装包：`AnkiSense Setup 0.1.15.exe`，216,424,485 字节。

## 更新内容

- 裁剪预检和保存后审核共用同一套配图规则。支持示意图、表格、统计图、公式、照片和文字截图，包含完整讲义页；不再只允许独立示意图通过。
- 答案侧允许包含答案文字；题目侧仍拦截提前泄露答案的图片。来源、相关性、完整性和实际清晰度仍须合格，装饰图、未知或关键判断不确定不能自动通过。
- 自动生成的答案侧原页支持显式检查；无可验证来源的上传图仍需人工核对。
- “配图待处理”改为“配图待核对”，明确已检查但仍需人工判断；答案侧不再显示容易误解的泄题警示。
- 配图规则和提示词升级至 v5。旧配图凭证不能替代当前检查，历史记录保留；图文整卡审核也须使用有效配图凭证。单图通过不等于整卡通过。
