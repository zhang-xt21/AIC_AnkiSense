## 结果

| 验收项 | 实测结果 |
| --- | --- |
| 网页配置生效 | 本机服务已读取云端模式、DeepSeek 地址和模型名 |
| 自动制卡任务 | 完成 1 个原文批次，提取 2 个知识点，生成 2 张草稿 |
| 独立质量检查 | 逐张检查均返回 clear，无疑点，无自动修正 |
| 引用校验与内容核对 | 两张卡片均引用连续原文；答案与自编原文一致 |
| 图片输入 | 清晰印刷测试图读取两次，一次提供参考文字，一次盲读；两次均与标准文字一致，无不确定项 |
| 本轮调用用量 | 6 次请求；输入 6,352 tokens，输出 1,291 tokens，合计 7,643 tokens |
| 等待耗时 | 文字任务约 32 秒；两次图片读取合计约 22 秒 |

自动任务使用 `max_cards=2`、`image_mode=off`、`source_mode=manual`。图片测试单独调用现有原页转录方法，再执行本地一致性政策检查。

## 样本与人工核对

文字材料由项目自编：

> 栈采用后进先出的规则：最后入栈的元素最先出栈。
>
> 队列采用先进先出的规则：最先入队的元素最先出队。

生成卡片分别考查栈和队列的进出规则，答案、评分点和逐字引用有原文依据。问句同时询问规则及其含义，存在可简化的重复表达，但没有观察到事实错误。

图片为先前本地基线中的 `clean_chinese.png`，标准文字为“栈遵循后进先出。最后入栈的元素最先出栈。”。原文没有识别错误，本次一致读取只能证明接口和这张图的读取成功。

## 验收范围与后续

本轮使用独立 `.local` 数据目录，结果保留为草稿，未添加到个人学习库。原始结果保存在 `.local/live-deepseek-20261019T134026Z/report.json` 和同目录 `image-report.json`；这些运行文件不进入 Git。

本轮覆盖自编短文字和一张清晰印刷图片。真实讲义、有错 OCR 的修正、复杂版面、来源新版本持久化及配图效果仍待下一轮实际样本验收。程序测试数量和本轮两个知识点的结果不能推算整体制卡准确率。

下一轮先导入 3–5 页获准的讲义，以 3 张卡片为上限，启用“自动校准原页并继续制卡”，配图选择“仅生成文字”。逐页检查差异、关键条件和数字，再核对卡片及其原文依据。
