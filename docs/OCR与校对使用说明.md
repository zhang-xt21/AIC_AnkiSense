# OCR 与原图校对

AnkiSense 先在本机提取 PDF 文字，需要时用本地 OCR 识别扫描页。有文字的当前片段可以直接生成卡片并自动检查，无需先逐页确认。原文校对是可选的修正入口；整卡及必要配图检查通过后即可学习，有疑点时再处理。你也可以主动请求支持图片输入的模型，获得当前页的校对建议和疑点；页面校对建议只供编辑参考，不会自动改写原文。

## 怎么使用

1. 启动项目并打开 [AnkiSense](http://127.0.0.1:8765/)。更新后刷新页面。
2. 进入「讲义制卡」的「导入讲义」，选择 PDF，建议先填 2–3 页的页码范围。
3. 「识别方式」保持「自动识别」：文字页直接提取，没有足够可用文字的页使用本地 OCR。
4. 查看系统建议的制卡张数，也可调整为 1–30 张，点击「开始制卡」。默认使用当前讲义全部有效原文，无需逐段勾选；需要限定片段时打开高级设置。后台分批生成的草稿会自动排队检查。识别失败或没有文字的页面会列为跳过范围，需重新识别或补入文字后才能用于制卡。
5. 需要核对时打开「检查原文」，或从卡片左侧定位它引用的页面。左边是原始页面，右边是识别文字；窄屏时上下排列。
6. 发现问题时，对照原图修正漏字、错误符号和顺序，再点击「保存原文」。也可按下一节让 AI 先标出疑点。只保存而未改字时，已有卡片及引用保持有效；实际改文后需更新卡片引用或重新生成。
7. 到「检查结果」查看进度。「机器审核通过」的卡片直接进入可学习状态，不需要再点人工批准。有疑点、调用失败或引用过期的卡片进入待处理；可修正后点「保存并检查」或「重试自动检查」。演示、粘贴文本等暂不支持自动批准，可展开「自行核对并处理」使用人工批准备用入口。

配置云端模型后，生成或保存草稿会自动排队检查，发送相关卡片文字、原文以及必要配图和对应原页，消耗模型 API 额度。自动检查不代表整份讲义已被人工校对，也不会把「已提取」的页面改成「已人工核对」。

已经导入过的旧 PDF 可以重新导入，从而进入新的逐页校对流程。旧材料和原来的练习记录保留。

## 用 AI 辅助校对（可选）

导入后会先在本机筛查编号跳项、疑似缺失分项、表格顺序、未完句、公式和低置信度行。页面显示「AI 仅校对疑点页（N）」，只请求这些页面，普通页面仍可直接制卡。疑点可展开定位到原页，不需要先逐页点击确认。筛查不是全文正确性证明：未识别出的整行没有 OCR 置信度，高分也可能漏字；跨页续接可能被误报。

新 OCR 结果保留每行文字、置信度和渲染图像上的像素坐标，历史导入没有这些字段也可继续使用。校订后的文字不会继承原始 OCR 的置信度。疑点筛查不调用模型、不改写原文、不增加源版本；视觉建议仍需选择采纳并保存。

先在侧栏「模型设置」配置云端 API，选择**支持图片输入、兼容当前请求格式**的模型。配置成功只表示地址、模型名和密钥已保存，不证明模型真的看懂了原页。在「检查原文」选择一页，点击「AI 校对当前页」；要处理多页，可点击「AI 检查未人工核对的 N 页」。批量操作会先确认发送范围，再按页顺序请求；可以停止后续页面，失败页不会自动重试。这是可选操作，不必为制作卡片检查整篇讲义。

每次请求只发送**当前 PDF 页渲染的 PNG 原图、该页当前已保存文字、页码**到你配置的模型服务，可能消耗 API 额度；不会整份上传 PDF。当前文字可能来自文字层、本地 OCR 或此前的人工校订。同一版本的建议可复用，重复查看未必再次调用模型。只想留在本机处理时，不点击 AI 校对即可继续手工校对。若讲义含个人信息，发送前先确认这一页是否适合交给所配置的服务商。

模型返回「AI 校对建议」后，先比较「当前已保存原文」与「AI 建议文字」，再检查列出的疑点。点击「将建议填入编辑框」只会填入未保存的编辑内容；已有未保存修改时不会覆盖。你可以继续改字，最后对照原页点击「保存原文」。建议结果本身不改变页面状态；生成草稿使用当前已保存文字，不会使用尚未保存的校对编辑或 AI 建议。模型失败时原页、已有文字和你的编辑内容保持不变。

AI 可能漏行、把表格串列、误读公式、上下标、箭头或图中关系，也可能把看不清的内容补成看似合理的文字。建议优先检查这些位置；模型没有标出疑点，不等于本页准确。若接口拒绝图片或结果格式不完整，请换支持视觉输入的模型，或直接手工校对。当前自动测试使用假模型验证请求、版本与失败处理，尚不能证明真实讲义的识别准确率。

## 识别不对怎么办

- 文字层乱码或遗漏：尝试「重新 OCR 此页」，也可以导入时选择「全部使用 OCR」。
- 识别失败：原始 PDF 保留，可以重试，或对照原图直接手工录入。
- 没有识别到文字：先检查原图；它不一定是空白页。确定为空白后再保存确认。
- 公式、下标、表格、图中箭头或多栏阅读顺序：发现疑点时可对照原图修正。AI 辅助校对和整卡机审都不保证这些内容一定正确。

切换页面时未保存文字会保留在当前标签页。出现版本冲突时，界面会保留你的编辑内容并展示最新保存文字；对照后再继续。

## 修改后，之前的卡片会怎样

仅保存原文、未改动文字时，保留版本、片段 ID 和已有卡片批准。实际校对修改和重新 OCR 会保留旧版本并创建新版本，引用旧版原文的卡片会回到待处理，旧批准失效。需要重新生成，或更新内容和引用后点「保存并检查」；当前版本通过后再进入学习和导出。

历史练习保留作答当时的题目、答案和原文快照，可以继续查看。原始识别文字也单独保留，可在校对区展开对照。

## 运行与保存

本地 OCR 不需要 API Key；只有主动使用 AI 辅助校对时，才需要配置支持图片输入的模型服务。换电脑时在项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\start.ps1
```

RapidOCR 3.9.2 与随包提供的 PP-OCRv6 small 模型在本机 CPU 上识别；首次安装依赖需要联网，本地识别本身不调用云端 AI。生成卡片、生成或保存后的自动检查、主动 AI 校对和答案分析会使用你配置的模型。

默认保存位置：

| 内容 | 项目内位置 |
| --- | --- |
| 原始识别、AI 校对建议、已确认版本、卡片与答题记录 | `data/ankisense.sqlite3` |
| 原始 PDF | `data/uploads/` |
| 页面预览图缓存 | `data/page-images/` |
| 本地 OCR 模型缓存 | `data/ocr-models/` |

专项测试请使用独立的临时数据目录，不要覆盖日常学习库。
