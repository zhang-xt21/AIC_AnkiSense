## 复现入口

先按[首页](../../README.md#源码启动)准备环境。常规离线检查在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
npm test
npm run test:browser:card-filters
```

桌面单元和打包程序验收在 `desktop/` 运行：

```powershell
npm test
node smoke.cjs --packaged
```

运行打包验收前，按[桌面说明](../../desktop/README.md)构建匹配版本，并确认 `smoke.cjs` 的参数及隔离数据安排。上述命令是复现入口，不代表本轮已经重跑；完整浏览器回归可运行 `npm run test:browser`。
