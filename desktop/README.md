# AnkiSense 桌面壳（Electron）

把现有网页端装进原生窗口的**薄壳**。它不包含任何网页逻辑，只负责启动后端、打开窗口并加载 `http://127.0.0.1:8765`。网页 UI 与后端仍位于 `../ankisense/`，由网页负责人维护。

## 启动方式

先在项目根目录装好后端依赖（`.venv`）。然后在 `desktop/` 目录：

```powershell
npm install
npm start
```

`npm start` 的默认行为是：若 `8765` 端口已有后端在跑，就直接连它；否则自己启动一个后端。

两种显式模式：

- `npm run start:dev` —— 只连**已运行**的后端（网页负责人日常开发时用它，避免端口冲突）。
- `npm run start:packaged` —— 始终自己启动后端（打包/演示时用）。

## 关键约定

- 端口号是 [main.js](main.js) 顶部的 `PORT` 常量（默认 `8765`）。若网页后端改端口，只需改这一处。
- 桌面壳不读写网页代码；网页内容改完刷新后端，桌面窗口自动显示新版。
- 打包成安装程序（electron-builder 等）是后续步骤，本目录目前只提供可运行的开发形态。
