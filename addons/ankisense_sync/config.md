# AnkiSense 本机同步设置

`connection_file` 是可选的本机 `plugin-connection.json` 完整路径，初次打开同步窗口时用作默认值。也可以保持为空，在 Anki 的“工具 → AnkiSense · 同步卡片…”中选择文件。

推荐在同步窗口选择文件，由插件保存当前电脑的完整路径；Anki 独立运行，不能假定它的当前目录就是 AnkiSense 项目目录。移动项目或数据目录后，请重新选择。若手工编辑 JSON，Windows 路径的反斜杠需要写成 `\\`，也可使用 `/`；不要复制另一台电脑的路径。

每个 Anki 资料会分别记住连接文件路径和上次同步的目标牌组，并保存稳定的资料标识。连接凭据只从连接文件读取；不要把 token 或模型 API Key 填入此配置。

目标牌组用于新增卡片，已有卡片保留原牌组与学习进度。可明确选择“新建牌组…”；新牌组在同步时创建。未批准或来源失效的卡片不会同步，Anki 中的手工修改会保留并列为冲突。

本插件首版只连接本机服务并同步文字与配图，不调用云端 AI，不提供 PDF 阅读或答案输入窗口。
